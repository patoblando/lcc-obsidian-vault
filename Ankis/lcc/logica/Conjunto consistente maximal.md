Defina conjunto consistente maximal. Y de un ejemplo.

---

Un conjunto $\Gamma \subseteq Prop$ es consistente maximal si y solo si:
- $\Gamma$ es consistente y
- Para todo $\Gamma'$ consistente tal que $\Gamma \subseteq \Gamma'$, se cumple $\Gamma = \Gamma'$.

Ejemplo: $\Gamma = \left\{ \phi : \left[ \! \left[ \phi \right] \! \right]_{v} = True \right\}$, para alguna valuación $v$.
